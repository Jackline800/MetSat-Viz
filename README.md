# 🛰️ MetSat-Viz (氣象衛星遙測視覺化)

*透過直觀、互動式的網頁介面，呈現全球氣象衛星的分佈現況、技術演進與衛星產品架構。*

---

## 🌐 網頁展示
(建議使用 Ctrl + 點擊，或滑鼠右鍵另開分頁)

### 1. 🌍 全球氣象衛星軌道分佈圖 (SAT_PRO)
視覺化呈現地球靜止軌道 (GEO) 與低軌／極軌衛星 (LEO) 配置。 <br>
👉 [點此觀看系統](https://sat-info.com/SAT_PRO/index.html)

### 2. 📊 日韓氣象衛星世代演進 (HimaCOMS)
時間軸互動分析，含 Himawari 與 COMS/GK 系列演進。 <br>
👉 [點此觀看時間軸](https://sat-info.com/HimaCOMS/index.html)

### 3. 📋 向日葵 8 / 9 號觀測休止履歷監測系統 (Hima_ObsStop)
整合雙衛星觀測中斷紀錄，支援自動化每週爬蟲、臺灣地區觀測時差校正（扣除10分鐘延遲）與西元/民國雙曆法連動篩選。 <br>
👉 [點此觀看監測面板](https://sat-info.com/Hima_ObsStop/index.html)

### 4. 🛰️ 衛星例行產品總覽圖 (SAT_Product)
以互動式圖解呈現地球靜止衛星與極軌衛星例行產品，包含雲圖、對流、降水、沙塵、火點、氣膠、雲物理、地表與海表參數、植被、短波輻射量及日照時數等產品分類。網頁支援產品圖示與中心圖置換，並可調整圖像、文字、軌道線及產品位置，適合用於產品展示、簡報素材製作與內部說明。 <br>
👉 [點此觀看產品總覽](https://sat-info.com/SAT_Product/index.html)

---

## 🛠️ 架構說明

- **SAT_PRO/**：衛星軌道分佈主程式與衛星影像資料庫。
- **HimaCOMS/**：世代演進時間軸主程式與各系列酬載技術參數。
- **Hima_ObsStop/**：觀測休止監測系統。包含自動化更新爬蟲程式 (`update_data.py`)、動態資料庫 (`data.js`) 以及互動式前端監測面板 (`index.html`)。
- **SAT_Product/**：衛星例行產品總覽圖。包含互動式前端頁面 (`index.html`)，可調整產品圖示、中心圖、文字大小、圖像大小、軌道樣式與物件位置，並支援匯出目前版面 HTML。

---

## 📌 SAT_Product 功能重點

- **互動式版面調整**：可透過控制面板調整主要產品圖示、中心圖、文字大小、圖片大小及位置。
- **多種路徑樣式**：支援操場形、非橢圓環帶與大橢圓等產品排列路徑。
- **圖片置換**：中心圖與各產品圖可由使用者自行上傳替換。
- **可編輯文字**：標題、中心文字與產品名稱可直接在網頁中修改。
- **版面保存與匯出**：可將目前版面儲存在瀏覽器，或匯出為新的 HTML 檔案。
